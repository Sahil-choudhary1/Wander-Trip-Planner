# 🌍 Wander Trip Planner

An AI-powered travel planning web application that helps users plan their trips smartly. Built as a minor project using the MERN stack with AI integration.

---

## ✨ Features

- 🤖 **AI Trip Planning** — Get smart travel itineraries generated by AI
- 🔐 **User Authentication** — Secure login and signup system
- 💾 **Save Trips** — Save and manage your planned trips
- 📋 **View Trip Details** — View full itinerary details for each trip
- 🌙 **Dark Mode** — Toggle between light and dark themes

---

## 🛠️ Tech Stack

**Frontend:**
- React.js (Vite)
- Axios
- CSS

**Backend:**
- Node.js
- Express.js
- MongoDB + Mongoose
- Nodemon

**AI:**
- Gemini AI API

## 🚀 Getting Started

### Prerequisites
- Node.js installed
- MongoDB Atlas account
- Gemini AI API key

### 1. Clone the repository
```bash
git clone https://github.com/Sahil-choudhary1/Wander-Trip-Planner.git
cd Wander-Trip-Planner
```

### 2. Setup Backend
```bash
cd ai-travel-planner/backend
npm install
```

Create a `.env` file in the backend folder:
```
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
GEMINI_API_KEY=your_gemini_api_key
PORT=5000
```

Start the backend:
```bash
npm start
```

### 3. Setup Frontend
```bash
cd frontend
npm install
npm run dev
```

The app will run at `http://localhost:5173`
